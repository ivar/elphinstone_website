## Build Commands

- `npm run dev` — Build CSS in watch mode + start Hugo dev server (via `concurrently`)
- `npm run build` — Build CSS with Tailwind CLI, then Hugo production build

## Architecture

Static landing page for Elphinstone Farm built with Hugo + Tailwind CSS v4 + DaisyUI v5. No frontend framework.

- **`hugo.toml`** — Hugo site configuration (baseURL, title, disabled kinds)
- **`layouts/_default/baseof.html`** — Base HTML template (head, body wrapper, CSS link)
- **`layouts/index.html`** — Home page template (extends baseof; logo, hero, cards, footer)
- **`assets/css/style.css`** — Tailwind v4 source CSS (input to Tailwind CLI)
- **`static/images/`** — Static assets (logo.png, footer.png, logo.svg)
- **`static/fonts/`** — Self-hosted variable font woff2 files (Fraunces, Nunito)
- **`static/css/style.css`** — Built CSS output (generated by Tailwind CLI; gitignored)
- **`content/_index.md`** — Home page front matter (required by Hugo)

## Styling

Uses Tailwind CSS v4 syntax (`@import "tailwindcss"`, `@plugin`, `@theme` directives). DaisyUI components (`card`, `btn`, `hero`, `join`) are used throughout.

The custom `elphinstone` DaisyUI theme is defined in `assets/css/style.css` and activated via `data-theme="elphinstone"` on `<html>`. Colors use OKLCH and represent the landscape: primary=mountain teal, secondary=forest green, accent=golden sun. Main text color is `#404949`.

**Fonts:** Fraunces Variable (serif, headings) and Nunito Variable (sans-serif, body) — self-hosted as woff2 variable fonts in `static/fonts/`, sourced from `@fontsource-variable` npm packages. `@font-face` declarations are in `assets/css/style.css`. No external font dependencies. Base font size is 125%.

## CSS Build Pipeline

Tailwind CSS v4 CLI processes `assets/css/style.css` and outputs to `static/css/style.css`. Hugo then copies `static/css/style.css` into the built site unchanged. The Tailwind CLI automatically scans `layouts/` for class names.
